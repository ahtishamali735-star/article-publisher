Guía definitiva para usar Letras Góticas con Cloudflare Workers

En este artículo descubrirás cómo crear un generador de letras góticas Cloudflare Workers que convierta texto plano en estilos medievales de forma instantánea y sin servidor. Aprovecharemos la potencia de Cloudflare Workers y su almacén de datos distribuido Cloudflare KV para ofrecer una API de Unicode text styling que funciona en el borde, lo que garantiza una respuesta en milisegundos sin importar la ubicación del usuario. Si buscas una solución de edge computing texto decorado para tu sitio o aplicación, sigue leyendo y aprende a implementarla paso a paso.

1. Arquitectura y flujo de datos

Antes de escribir código, es útil visualizar cómo se interconectan los componentes:

  1. Cliente → solicita la transformación a través de una petición HTTP (GET o POST).
  2. Cloudflare Workers → recibe la petición, valida los parámetros y llama a la lógica de conversión.
  3. Cloudflare KV → almacena en caché los resultados de conversiones frecuentes, reduciendo la carga del worker.
  4. Respuesta → el worker devuelve el texto convertido, listo para copiar y pegar.

Este enfoque permite que la letras góticas API se ejecute en la red de borde de Cloudflare, minimizando la latencia y ofreciendo alta disponibilidad sin necesidad de gestionar servidores tradicionales.

2. Preparar el entorno de desarrollo

2.1 Instalar wrangler

wrangler es la herramienta oficial de Cloudflare para crear, probar y desplegar workers. En tu terminal ejecuta:

npm install -g @cloudflare/wrangler

2.2 Inicializar el proyecto

Crea una carpeta nueva y genera la estructura básica:

mkdir generador-gotico && cd generador-gotico
wrangler init --type=javascript

El comando crea un archivo src/index.js (el entry point) y un wrangler.toml con la configuración del proyecto.

2.3 Configurar Cloudflare KV

En el portal de Cloudflare, dirígete a Workers → KV Namespaces y crea un namespace llamado GOTIC_CACHE. Copia el ID del namespace y añádelo al archivo wrangler.toml:

kv_namespaces = [
  { binding = "GOTIC_CACHE", id = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" }
]

Con este binding, el worker podrá leer y escribir en KV usando la variable GOTIC_CACHE.

3. Implementar la lógica de conversión

3.1 Mapa de caracteres Unicode

Las letras góticas se basan en los bloques Unicode Mathematical Fraktur y Mathematical Bold Fraktur. Crearemos un objeto JavaScript que mapee cada letra latina a su equivalente gótico:

const GOTHIC_MAP = {
  a: "𝔞", b: "𝔟", c: "𝔠", d: "𝔡", e: "𝔢", f: "𝔣",
  g: "𝔤", h: "𝔥", i: "𝔦", j: "𝔧", k: "𝔨", l: "𝔩",
  m: "𝔪", n: "𝔫", o: "𝔬", p: "𝔭", q: "𝔮", r: "𝔯",
  s: "𝔰", t: "𝔱", u: "𝔲", v: "𝔳", w: "𝔴", x: "𝔵",
  y: "𝔶", z: "𝔷",
  A: "𝔄", B: "𝔅", C: "ℭ", D: "𝔇", E: "𝔈", F: "𝔉",
  G: "𝔊", H: "ℌ", I: "ℑ", J: "𝔍", K: "𝔎", L: "𝔏",
  M: "𝔐", N: "𝔑", O: "𝔒", P: "𝔓", Q: "𝔔", R: "ℜ",
  S: "𝔖", T: "𝔗", U: "𝔘", V: "𝔙", W: "𝔚", X: "𝔛",
  Y: "𝔜", Z: "ℨ"
};

3.2 Función de transformación

function toGothic(text) {
  return Array.from(text).map(ch => GOTHIC_MAP[ch] || ch).join("");
}

Esta función conserva cualquier carácter que no tenga representación gótica (espacios, símbolos, números), lo que evita errores de codificación.

3.3 Cacheo inteligente con KV

Para evitar recomputar conversiones idénticas, usaremos KV como caché:

async function getOrCreateGothic(text) {
  const key = `gothic:${crypto.subtle.digest('SHA-256', new TextEncoder().encode(text)).then(buf => Array.from(new Uint8Array(buf)).map(b=>b.toString(16).padStart(2,'0')).join('')}`;
  // Intentamos leer del cache
  const cached = await GOTIC_CACHE.get(key);
  if (cached) {
    return cached;
  }
  // Si no está, generamos y guardamos
  const result = toGothic(text);
  await GOTIC_CACHE.put(key, result, { expirationTtl: 86400 }); // 24 h
  return result;
}

Nota: En el ejemplo anterior, la generación de la clave hash está simplificada; en producción se recomienda usar una función hash síncrona o una librería ligera para evitar la complejidad de crypto.subtle dentro del worker.

3.4 Handler del worker

export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    const text = url.searchParams.get("text") || "";
    if (!text) {
      return new Response(
        JSON.stringify({ error: "Parámetro 'text' requerido" }),
        { status: 400, headers: { "Content-Type": "application/json" } }
      );
    }

    const gothic = await env.GOTIC_CACHE ? await getOrCreateGothic(text) : toGothic(text);
    const json = { original: text, gothic };
    return new Response(JSON.stringify(json), {
      headers: { "Content-Type": "application/json; charset=utf-8" }
    });
  }
};

El worker expone una API sencilla:
GET https://<tu-dominio>.workers.dev/?text=hola+mundo

Respuesta JSON:

{
  "original": "hola mundo",
  "gothic": "𝔥𝔬𝔩𝔞 𝔪𝔲𝔫𝔡𝔬"
}

4. Despliegue y pruebas

4.1 Publicar el worker

wrangler publish

Una vez publicado, Cloudflare distribuirá el código a sus centros de datos globales. Puedes validar la latencia con herramientas como curl -w "%{time_total}\n" desde diferentes regiones.

4.2 Probar la caché KV

Ejecuta dos peticiones idénticas y observa la diferencia en los tiempos de respuesta. La segunda debería ser notablemente más rápida, ya que el resultado proviene del cache de KV.

4.3 Seguridad básica

Limita la longitud del parámetro text (por ejemplo, 500 caracteres) para evitar abusos y añade encabezados CORS si tu frontend los necesita:

if (text.length > 500) {
  return new Response(JSON.stringify({ error: "Texto demasiado largo" }), { status: 413 });
}

5. Integración front‑end

Para que los usuarios puedan convertir texto directamente desde tu sitio, basta con una pequeña llamada JavaScript:

<input id="input" placeholder="Escribe aquí" />
<button id="convert">Convertir</button>
<pre id="output"></pre>

<script>
document.getElementById('convert').addEventListener('click', async () => {
  const txt = document.getElementById('input').value;
  const resp = await fetch(`https://<tu-dominio>.workers.dev/?text=${encodeURIComponent(txt)}`);
  const data = await resp.json();
  document.getElementById('output').textContent = data.gothic;
});
</script>

Esta arquitectura es escalable, segura y fácil de integrar en cualquier proyecto web o móvil. Si buscas más ejemplos de letras góticas listas para copiar, visita la página de referencia: Letras Góticas – Letras Bonitas.
